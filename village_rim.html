Description

Village Rim is a 2D action-adventure game set across two parallel worlds, where the player switches between realms to solve encounters, protect altars, and survive escalating enemy waves.

Technology Used

Unity (C#), Universal Render Pipeline (URP), custom shaders, pixel-art assets, NavMesh AI, and custom tooling for debugging and performance profiling.

Development Focus

Designed and implemented the core gameplay systems, including altar and elemental mechanics, dual-world interactions, invader wave progression, and cross-scene state persistence. Developed enemy systems covering behavior design, spawning logic, and wave orchestration, including specialized enemy types with custom abilities, interaction rules, and combat patterns.

Built AI behavior and navigation using Unity NavMesh, and implemented engine-level debugging and visualization tools (directional guidance, camera state visualization, and runtime state probes) to support rapid iteration and tuning. Optimized rendering and update pipelines for stable real-time performance, and contributed to combat effects, healing mechanics, audio integration, and overall gameplay balance.
